# ChainWaste CLI

Run from the repository root. Start Besu and deploy the contracts as described
in [network setup](../network/README.md). The CLI reads the local deployment,
ABI and demo accounts generated by those steps. Run one transaction at a time.

```powershell
node cli/chainwaste.mjs --help
node cli/chainwaste.mjs accounts
```

Each write command selects the appropriate local demo account and prints the
actor, transaction hash, receipt block, gas used, and decoded events. The
regulator can grant an application role with `register <role> <address>`.
This does not replace the local wallet assigned to that command.

## Demo with a fresh manifest

Create a small local test document and use the transporter and processor
addresses printed by `accounts`:

```powershell
Set-Content -Encoding utf8 demo-manifest.txt "ChainWaste B3 demo"
Set-Content -Encoding utf8 demo-seal.txt "Demo seal"
Set-Content -Encoding utf8 demo-proof.txt "Treatment proof"
Set-Content -Encoding utf8 demo-resolution.txt "Auditor reviewed the discrepancy"
$deployment = Get-Content network/generated/deployment.json -Raw | ConvertFrom-Json
node cli/chainwaste.mjs create $deployment.accounts.transporter $deployment.accounts.processor B3-DEMO 10000 demo-manifest.txt
```

Set `$id` to the ID in the `ManifestCreated` event. If a write command exits
with an error, inspect the manifest and any printed transaction hash before retrying.

```powershell
node cli/chainwaste.mjs pickup-weight $id 10000 demo-seal.txt
node cli/chainwaste.mjs pickup $id
node cli/chainwaste.mjs received-weight $id 9800
node cli/chainwaste.mjs receive $id
node cli/chainwaste.mjs treat $id demo-proof.txt
node cli/chainwaste.mjs show $id
node cli/chainwaste.mjs audit $id
node cli/chainwaste.mjs verify $id demo-manifest.txt
```

Repeat with a new manifest and record 1,000 kg instead of 9,800 kg. Receipt
emits `AnomalyDetected`, and treatment is blocked until the auditor resolves
the flag with `node cli/chainwaste.mjs resolve $id demo-resolution.txt`.
The auditor can also use `flag $id <reason-file>` for a manual review.

To demonstrate document tampering, pass a different file to `verify`. It
prints both hashes and exits with status 1 when they differ. The hash uses
the exact file bytes, including line endings. Demo documents and private
keys stay local.
